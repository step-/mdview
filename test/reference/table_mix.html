DESCRIPTION

Version note:
New mdview versions do not support the code block table feature presented in the following examples.

mdview supports tables in a limited way: it can recognize table syntax, and it displays the table as an unstyled code block. Therefore, if the original table text is aligned, the output table will look aligned.

Inside the table block all characteristics of a code block apply. For instance, _, *, and +++ represent themselves; quotes don't become smart quotes, and so on.
